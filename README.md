# Slide Skill

A Claude skill that turns meeting notes into a VP-ready leadership deck, built through the Gamma connector in the Meridian brand.

- Fixed 10-section slide spine, 8-12 slides
- Assertion headlines with the number in the title
- One idea per slide, evidence on every slide, strict density limits
- Meridian brand: navy #1B2A4A, amber #E8A33D, Inter, "Meridian - Confidential" footer, tagline "Clarity. Momentum. Results."

## Contents

- `slide-skill/SKILL.md` - the skill definition

## Install

Zip the `slide-skill` folder and upload it in Claude under Settings > Capabilities > Skills.

## Note

The Gamma free plan caps decks at 10 cards, so the skill's merge rules may be needed to stay within that limit.
